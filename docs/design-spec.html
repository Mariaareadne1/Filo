The map your friends would draw, as a system.

Filo's identity rests on three moves — the thread, the sticker shadow, the italic accent word. Every screen uses all three, and nothing is allowed to compete with them. This page is the source of truth for tokens, type, and components, pulled directly from the code.

01 · FOUNDATIONS

Three signatures

Used together on every screen. If a design breaks one of these, it isn't Filo.

The thread

One red, used with precision

Red #d8423a is the only accent — the FAB, the active rank, save confirmations, the wordmark period, and one italic word per title. Nowhere else.

Sticker shadow

Hard offset, zero blur

Cards carry a 2px 2px 0 ink shadow with a 1px ink border and square corners. They look stuck to the paper — no soft elevation.

Italic accent word

One word in red

Display titles are Fraunces with a single italic red word: "different tastes, same map."

Anti-patterns — never ship
  • Star ratings or 0–10 scores — impressions only
  • Sponsored / algorithmic feed content
  • Infinite scroll — the feed stops
  • Gradient backgrounds
  • Emoji in core UI (user content only)
  • More than 4 cards above the fold

Doc ⇄ code tension

The README bans "beige/cream backgrounds," yet Paper ships an off-white #fafaf8 ground. Read it as paper, not beige — it's the intended default. Worth reconciling in the README.

06 · ACCESSIBILITY

Reachable, not just readable

  • Contrast: inkMute → 0.55α (~4.5:1); never use it for primary text.
  • Labels: every icon-only control has role + label — tabs, FAB ("Add a new pin"), markers (place, category), OTP, modal backdrops.
  • Live regions: upload toast is polite; spinners labeled.
  • Font scaling: pictographic glyphs opt out; text scales; prefer minHeight over fixed height.
  • Never color alone: category = glyph + color; status = red + "✓ visited".
07 · USAGE

Do & don't

Do
  • One red thread per screen, on the single most important thing
  • Square corners + hard shadow for content; rounded glass only for chrome
  • One italic red word per display title
  • Always show real place, person, neighborhood
Don't
  • Add a second accent, a gradient, or a soft content shadow
  • Introduce a fourth typeface
  • Use star ratings or numeric scores
  • Stack more than 4 cards above the fold
